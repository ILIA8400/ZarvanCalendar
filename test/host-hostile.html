Below: the same calendar in shadow: true mode. The scoped reset already beats a plain * { … } on specificity, which is why CHECK 1 passes. What it cannot beat is an ID-scoped universal selector such as #app * { box-sizing: content-box !important } — that is (1,0,0) against the reset’s (0,1,0).
